Carpeta de Pruebas del Sistema
En esta carpeta se encuentran los distintos códigos desarrollados durante la fase de pruebas e integración del sistema completo.

Aquí se incluyen scripts utilizados para:

Aprender a abrir y gestionar la cámara desde Python.

Validar la captura de imágenes con OpenCV.

Integrar YOLOv5 para detección de mandarinas.

Conectar la red de clasificación en TensorFlow.

Realizar pruebas conjuntas entre cámara, detección y clasificación.

Progresión de Desarrollo
Los archivos reflejan la evolución del sistema, desde pruebas básicas e independientes hasta la integración parcial de todos los componentes.

Las etapas incluyen:

Captura de imagen funcional.

Detección correcta con YOLOv5.

Recorte automático mediante coordenadas.

Envío de la imagen recortada a la red de clasificación.

Visualización de resultados en tiempo real.

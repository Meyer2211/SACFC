# Impresiones_3D

## Propósito

Esta carpeta reúne los recursos de diseño mecánico utilizados para fabricar, mediante impresión 3D, las piezas físicas de los mecanismos de actuación (puertas/desviadores) del sistema de clasificación de mandarinas.

## Contenido

- **Archivos STL** — modelos 3D listos para impresión, correspondientes a las piezas del mecanismo de desvío diseñadas para este proyecto.
- **Archivos de terceros** — paquetes descargados de repositorios de diseño externos, con mecanismos de referencia (puertas accionadas por servo, actuadores lineales por servo) utilizados como base o inspiración para el diseño propio.

## Relación con el sistema de clasificación

Las piezas contenidas en esta carpeta forman el mecanismo físico que el sistema activa para desviar cada mandarina hacia el carril correspondiente ("buena" o "mala") sobre la banda transportadora, según la clasificación producida por el software. Estas piezas son accionadas por los servomotores que el sistema controla mediante Arduino.

## Alcance

Esta carpeta no contiene código fuente del sistema. Su contenido corresponde exclusivamente a diseño mecánico y recursos de terceros asociados a la fabricación física de los mecanismos de actuación.
